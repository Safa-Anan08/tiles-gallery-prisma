#  Tiles Gallery

A modern full-stack tile marketplace built with **Next.js**, featuring authentication, wishlist, cart management, user profiles, and responsive UI.

---

##  Live Features

###  Authentication
- Email / Password Login
- Google Sign In
- Secure session handling
- Auto logout redirect

---

###  Homepage
- Beautiful tile showcase
- Featured tile cards
- Responsive layout
- Smooth hover animations

---

###  All Tiles Page
- Browse all available tiles
- Responsive grid layout
- Clean card design
- View detailed product info
- Search and filters
---

###  Tile Details Page
Each tile includes:

- Large preview image
- Description
- Price
- Category
- Material
- Dimensions
- Stock status

Actions:
-  Add / Remove Wishlist
-  Add / Remove Cart

---

###  Wishlist System
Users can:

- Add tiles to wishlist
- Remove from wishlist
- View wishlist inside profile
- Real-time UI update

---

###  Cart System
Features:

- Add / Remove cart items
- Cart item counter in navbar
- Auto badge sync
- Dedicated cart page
- Cart preview in profile page

---

### My Profile
User dashboard includes:

- Profile image
- Name & email
- Edit profile
- Wishlist section
- Cart section

---

###  Responsive Navbar
Desktop:
- Home
- All Tiles
- Profile
- Cart
- Login / Logout

Mobile:
- Hamburger menu
- Optimized navigation

---

###  Toast Notifications
Interactive feedback for:

- Login required
- Added to wishlist
- Removed from wishlist
- Added to cart
- Removed from cart
- Profile updated

---

##  Installation

### Clone repository

bash
git clone <your-repo-link>


### Install dependencies

bash
npm install


### Run development server

bash
npm run dev
